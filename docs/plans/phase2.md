# Infinito Mourinho 改善 第2段階（ターミナルの Claude Code への指示）

提案レポート: https://claude.ai/artifact/NFA2dSDGLcXYabkk6Ttcc9
第1段階（`docs/plans/phase1.md`）は PR #12〜#16 で完了。第3段階（ファン予想・クイズ・記録トラッカー）はレポートを参照。

目的: 「ここに来ればわかる」と言われる中身の厚みを作る。検索で拾われるページをさらに増やし、毎日来る理由を作る。
背景: 第1段階で 141 URL・シェア画像・トップの並び替えまでできた。名言は15本で出典がなく、4本は年もない。数字・ライバル・ニュースと試合の専用ページはまだない。
やらないこと: 投票などサーバー保存が必要な機能（第3段階で D1 を使う）、移籍の噂を事実として書くこと、出典を確かめていない数字や発言を載せること。

1つずつ別のブランチ・PRで進めてください。CLAUDE.md の作業の流れとサイトのルールに従うこと。

## 事実の扱い（全項目に共通）

- 新しく載せる名言・数字・出来事には、JSON に出典を持たせる（`source: { url, publisher, date }`）。出典は報道機関・クラブ・リーグ・UEFA などの公式な記録に限る。ファンの Wiki や SNS の転載は出典にしない。
- 追加は1回10件まで。PR には、追加した各件の出典 URL を一覧にし、実際に開いて内容を確かめた日を書く。
- 日付や数字が出典どうしで食い違うときは載せない（PR に「見送り」として書く）。
- 時代（クラブ）との対応は、年から推測せず `era`（`history.json` の id）を明示する（PR #13 の学び）。
- `test/` に、出典のない項目があると落ちるテストを足す。

## 1. 名言のデータを拡張し、既存15本に出典を付ける

- `quotes.json` に `date`（分かる範囲で `YYYY-MM-DD` か `YYYY`）・`era`・`source`・`tags`（例 `rivals` `humour` `pressure`）を足す。
- 英語以外で言った名言は、`original: { lang, text }` に原文を、`text` に英訳を持たせ、個別ページに原文も出す。
- 既存15本のうち、出典を確認できないものは外す（`docs/review-lessons.md` に経緯を残す）。年のない4本（pressure・harry-potter・omelettes・melons）を優先して確かめる。
- 個別ページに出典のリンクを出す。`era` があれば、その時代のページと相互にリンクする。

## 2. 名言を100本へ（10本ずつ）とタグのページ

- 項目1の形式で、10本ずつ PR を分けて追加する。名言ごとのシェア画像は `npm run og` で作ってコミットする。
- タグごとの一覧ページ `/quotes/tag/{tag}/`（es・pt は言語ごとのスラッグ）を作り、名言一覧からも絞り込めるようにする。

## 3. タイトル一覧と「数字で見るモウリーニョ」

- `/trophies/`: 獲得タイトルを時代・大会ごとに一覧にする。データは `trophies.json`（大会・シーズン・クラブ・`era`・出典）。
- `/stats/`: 通算の指揮試合数・勝率・クラブ別成績・主な記録。数字ごとに出典と「何年何月時点」を書く。現所属クラブの数字は、時点を明記して手で更新する（ESPN の自動取得の数字と混ぜない）。
- 時代のページに、その時代のタイトルと成績を出す。

## 4. ライバルとの対戦成績

- `/rivals/{id}/`（例 `/rivals/guardiola/`）を8〜10人分。対戦成績（勝・分・負、主な試合）と、互いの発言を出典つきで載せる。
- 対戦成績は、どの大会を含むかと、何年何月時点かを明記する。出典で数え方が違うときは、採用した数え方を書く。

## 5. On this day（この日のモウリーニョ）

- `onthisday.json`（`MM-DD`・年・出来事 en/es/pt・`era`・出典）。365日すべてを埋めることは目指さず、確かめられた日だけを載せる。
- トップの「今日の名言」の近くに、今日の出来事を出す。ビルド時ではなく `app.js` で今日の日付から選び、該当がなければ直近の日を出す（日替わりのため）。
- 月ごとの一覧 `/on-this-day/{month}/`（例 `/on-this-day/october/`）を作る。

## 6. 今週の発言

- `remarks.json` に、現在の記者会見などでの発言を、出典（記事か公式の動画）つきで手で追加する。1回1〜3本。
- トップのニュースの下に最新の3本を出し、過去の分は `/remarks/` にまとめる。
- フィードから自動では作らない（発言の正確さを確かめられないため）。

## 7. ニュースと試合の専用ページ

- `/news/`: 3言語それぞれのニュース（KV の `news:{lang}`）の全件。ページは静的に作り、中身は今と同じく `/api/news` から `app.js` が埋める。
- `/matches/`: 今季の結果と日程。ESPN のデータで足りる範囲で、`/api/matches` を拡張する（Worker と KV の書き込み回数が無料枠に収まることを PR に書く）。
- ヘッダーの News・Matches・Videos を、トップのアンカーからそれぞれのページへのリンクに置き換える（Videos はトップの動画欄のままでよい）。

完了条件（項目ごと）: `npm run build` と `npm test` が通り、新しいページが3言語分出力され、sitemap に載っていること。事実を足した PR は、出典 URL の一覧と確認した日を PR に書くこと。見た目が変わる PR は `npm run screenshot -- --pr <番号>` の画像を付けること。
