# Infinito Mourinho 改善 第3段階（ターミナルの Claude Code への指示）

提案レポート: https://claude.ai/artifact/NFA2dSDGLcXYabkk6Ttcc9 （「6. 新しいコンテンツ」と「進め方の提案」）
第2段階（`docs/plans/phase2.md`）は PR #26〜#49 で完了。

目的: 再訪と拡散の理由を作る（ファンが次を待つ、結果を友達に送りたくなる）。
背景: 第2段階で数字・ライバル・On this day・今週の発言・試合の専用ページができた。発言は毎週のルーティンが PR を作る。
やらないこと: 出典のない事実を足すこと、移籍の噂を事実として書くこと、ログインや個人情報の保存、外部の SDK・広告。

1つずつ別のブランチ・PR で進める。CLAUDE.md の作業の流れとサイトのルールに従う。

## 1. クイズ（D1 は使わない）

- `/quiz/`・`/es/trivia/`・`/pt/quiz/`。問題は `trophies.json` の各タイトルから作る「どのクラブで取ったか」の4択（`scripts/content.mjs` の `quizQuestions`）。新しい事実は足さない。
- 選択肢の誤答は、監督として率いたクラブ（`stats.json` の `clubs` と `current`）から選ぶ。アシスタント時代のクラブは出さない。
- HTML に10問と、各問の答えと出典（`<details>`）を入れる。JS なしでも答えを確かめられる。`app.js` が正誤・点数・別の10問を出す。
- 次の段階: 結果をシェアできるようにする（点数入りの文言を共有。画像はビルド時に作れる範囲で）。名言から「誰に向けた発言か」を当てる問題は、`quotes.json` の出典つきの場面が十分にそろってから。

## 2. ファン予想（D1 を使う）

- 次の試合のスコアを投票し、試合後に結果と正解者の割合を出す。保存は Cloudflare D1（KV は書き込みの無料枠が1日1,000回で足りない）。
- 着手前にオーナーと決めること: 連投・スパム対策（Turnstile、IP ごとの上限）、投票を何日残すか、表示する集計の粒度。個人を特定できる情報は保存しない。
- 完了条件: 無料枠（D1 の書き込み1日10万回、Functions の実行1日10万回）に収まる見積もりを PR に書くこと。

## 3. 記録トラッカー

- 「通算○○試合まであと何試合」など、近づいている節目。数字の起点は出典つきの値（`stats.json`）にし、起点より後の試合を ESPN の結果から数えるか、出典の新しい値を待つかを着手前に決める（`stats.json` の `current` と同じく、数え方と時点をページに書く）。

完了条件（項目ごと）: `npm run build` と `npm test` が通り、新しいページが3言語分出力され、sitemap に載っていること（`noindex` のページは載せない）。操作できる要素を足したら `test/flows/` にフローを足し、`npm run verify` の結果を PR に書くこと。見た目が変わる PR は `npm run screenshot -- --pr <番号>` の画像を付けること。
