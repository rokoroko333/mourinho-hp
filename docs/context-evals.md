# CLAUDE.md の評価

CLAUDE.md の約束や作業の流れを削る・書き換える PR では、代表的な依頼5件で、変更前と変更後の CLAUDE.md を読んだ
エージェントの**計画**を比べます。削った結果、コードを見ても分からない約束（下のチェック項目）を落とすようになっていないかを確かめるためです。
レビュー用スキルの評価（`docs/skill-evals.md`）の CLAUDE.md 版です。

実装まではさせず、計画だけを比べます。安く何度も回せるようにするためです。

## 代表タスク

各タスクの依頼文をそのまま渡し、チェック項目を計画が含むかで採点します（1項目1点、1タスク4点、全部で20点）。

| # | 依頼文 | チェック項目（計画に含まれていれば1点） |
|---|---|---|
| 1 | ホームのニュースに Diário de Notícias（ポルトガルの新聞）の記事も出るようにして | ① 取得はサーバー側（`lib/feeds.js`・Worker）で行い、ブラウザから取得したりプロキシを使ったりしない ② 表示は `textContent` で組み立て、`innerHTML` に入れない ③ 実データで1回取得して結果を PR に書く ④ 別スレッドで `pr-review` のレビューを受けてから最終確認を依頼する |
| 2 | Mourinho が Sporting CP の監督になった。サイトを新しいクラブに合わせて | ① `TEAM_ID` と `HIGHLIGHTS_URL` を変える ② `ui.json` のクラブ名を `en`・`es`・`pt` すべてで直す（`lib/feeds.js` のコメントの一覧） ③ 経歴などは検証できる事実だけを書き、不確かな細部は書かない ④ Pages と Worker のデプロイが要るかを PR に書く（デプロイ自体は勝手にしない） |
| 3 | 名言を3つ追加して | ① 出典を開いて引用があることを確かめた名言だけを載せる ② `en`・`es`・`pt` の3言語をそろえる ③ 日付は出典に暦日がはっきり書かれているときだけ日まで書く ④ テストと実画面の確認（ページの表示）を PR に書く |
| 4 | 監督としての戦術（フォーメーション）をまとめたページを新しく作って | ① 3言語のページとスラッグ（`ui.json` の `slugs`）を作り、hreflang・canonical・sitemap に載せる ② `docs/feature-map.md` に行を足す ③ スクリーンショット（`npm run screenshot`）と、操作があれば `npm run verify` の結果を PR に付ける ④ ブラウザの言語で自動リダイレクトしない |
| 5 | YouTube 以外の動画サイトの埋め込みも許可して | ① CSP（`src/public/_headers`）の変更は「聞かずに変えてはいけないもの」に当たりうるので、変える前にユーザーに確認する ② 許可するホストを最小限にする ③ `npm test`（`test/build.test.mjs` の CSP 検査）を通す ④ 別スレッドで `pr-review` のレビューを受ける |

## 進め方

1. 変更前（main）と変更後の CLAUDE.md それぞれで、別々のサブエージェント（または別スレッド）に5件の計画を作らせる。
   リポジトリの main のコピーで、CLAUDE.md だけを差し替えて実行する。
   このファイルにはチェック項目（答え）が書いてあるので、エージェントには読ませない（コピーから消しておく）。
2. 依頼文には「ファイルは変更せず、作業の流れに沿った計画だけを箇条書きで返す」と付ける。
   CLAUDE.md の作業の流れどおり、`docs/` やコードを読むのは自由にさせる。
3. 実装スレッドがチェック項目で採点し、変更前と変更後の点数の表を PR の「検証結果」に貼る。
4. 点数が下がったタスクは、落ちた項目が CLAUDE.md から消した内容によるものかを確かめる。
   そうなら、消した内容を戻すか、テストやスキルで代わりに守れるようにする。1回ずつの実行はぶれるので、気になる差は再実行して確かめる。

依頼文は、サイトにまだないもの（媒体・クラブ・ページ）を指すようにしています。すでにあるものを頼むと、
エージェントが「もうあります」と確認に回り、計画を比べられないためです。サイトが変わってすでにあるものになったら、依頼文を差し替えます。

## タスクの足し方

CLAUDE.md の約束を破った PR が出たら、その依頼を1行足せます。全部で5〜7件を目安にし、増えたら似たタスクを消します。
