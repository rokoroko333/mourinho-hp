# 過去の指摘メモ

作業の計画時とレビュー時に、**関係する行だけを検索して**読みます（全文は読まない）。
レビューが「合格」になったら、最終確認の前に実装スレッドが同じ PR で1行ずつ追記し、週1回の整理で検証・昇格・削除します。目安は全体で50行以内。

書式: `- YYYY-MM-DD #PR番号 要点（検証: YYYY-MM-DD）`

- 「検証」は、その行が今も正しいことを最後に確かめた日です。
- 繰り返し出た行は CLAUDE.md かレビュー用スキル、機械的に確かめられるものは `test/rules.test.mjs` に昇格させ、ここからは消します。

## 指摘

- 2026-10-28 #1 手順書の同じ決まりを複数ファイルに書くと、片方だけ直して食い違う。直すときは grep で全箇所を探す（検証: 2026-10-28）
- 2026-10-28 #1 Stop フックは2回目の停止で通るため、通った後の扱いを文書にも書く（検証: 2026-10-28）
- 2026-10-29 #2 外部 API の取得は手で作ったデータのテストだけでは壊れていても緑になる。実データで1回呼んで結果を PR に書く（検証: 2026-10-29）
- 2026-10-29 #2 移籍で変わる値（ESPN の TEAM_ID・ハイライトの URL・ui.json のクラブ名）は複数箇所にある。変えるときは grep で全部探す（検証: 2026-10-29）
- 2026-10-29 #3 Google News の `site:` 検索は同じドメインの別言語版（marca usa など）や本文で触れただけの記事も返す。出典名・タイトル・日付で絞る（検証: 2026-10-29）
- 2026-10-29 #3 複数の取得元を `allSettled` でまとめると、1つが黙って欠けても気づけない。空だった取得元を Cron のレポートに出す（検証: 2026-10-29）
- 2026-10-29 #5 取得失敗を `null` や空配列で握りつぶすと、Cron のログで「拒否された」と「記事がない」を区別できない。失敗した件数をレポートに出す（検証: 2026-10-29）
- 2026-10-29 #6 `git remote get-url origin` には認証情報が入っていることがある。出力や PR に使うときは `owner/repo` だけを取り出す（検証: 2026-10-29）
- 2026-10-29 #7 一覧の上限を緩めて件数を埋めると、取得元が少ないとき1媒体が大半を占める。埋めるときも有限の上限を付ける（検証: 2026-10-29）
- 2026-10-29 #8 CSP の許可ホストとデータ側の検証がずれると、ブラウザで黙ってブロックされる。外部画像のホストは実データで確かめ、CSP は配信元のドメイン単位（`*.espncdn.com`）で許可する（検証: 2026-10-29）
- 2026-10-29 #12 文字列を語の境目で切る処理は、空白がないと `lastIndexOf` が -1 になり末尾が落ちる。境目がないときの切り方も書く（検証: 2026-10-29）
- 2026-10-29 #13 名言やエピソードを年だけで時代（クラブ）に結びつけると、境目の年（2004 年の Porto と Chelsea など）で別のクラブに割り当てて事実と違う表示になる。年だけで対応づけない（検証: 2026-10-29）
- 2026-10-29 #14 コミット済みの生成物を作り直すスクリプトは、先に消してから作ると途中で失敗したとき消えたままになる。一時フォルダに全部作ってから差し替える（検証: 2026-10-29）
- 2026-10-29 #18 Pages は 404.html がないと、存在しないパスにトップページを 200 で返す。ステータスだけで「ページがある」と判断しない（canonical のパスで確かめる）（検証: 2026-10-29）
- 2026-10-29 #18 「見えていない」「値が変わった」を確かめるステップは、要素や比較元がなくても通りうる。存在しないときは失敗させる（検証: 2026-10-29）
- 2026-10-29 #19 コードを正規表現で調べるテストは、書き方が少し違うだけで空振りして緑のままになる。対象が何件見つかったかも assert し、わざと違反させて落ちることを確かめる（検証: 2026-10-29）
- 2026-10-29 #20 公開済みのページを消すときは、`src/public/_redirects` に一覧などへの 301 を足す。足さないと、検索や外部リンクからの流入が 404 になる（検証: 2026-10-29）

## うまくいった手順

- 2026-10-29 #2 実装の経緯を渡さない別のサブエージェントに pr-review を任せると、レビューが1回で終わり先入観も入らなかった（検証: 2026-10-29）
- 2026-10-29 #6 レビューのルーティンに GitHub のフック（PR の作成・更新）を付けると、プッシュ直後にレビューが自動で付いた（検証: 2026-10-29）
- 2026-10-29 #15 画面撮影では確かめられないクリック後の動作は、ヘッドレス Chrome を DevTools Protocol（Node 22 の WebSocket）で動かし、クリックして DOM とコンソール（CSP 違反）を見ると確かめられた（検証: 2026-10-29）
- 2026-10-29 #16 下書きの PR を「ready」にしてもフック（opened・synchronize）は起動しない。PR 本文を書き終えてから RemoteTrigger の run でレビューを起動すると、空の本文をレビューされずに済んだ（検証: 2026-10-29）
- 2026-10-29 #20 名言の出典調べは、5本ずつのサブエージェントに「ページを開いて本文に引用があることを確かめた出典だけ」を返させると、文脈の誤り（harry-potter は Chelsea でなく Real Madrid）や、出典のない名言（2本）を見つけられた（検証: 2026-10-29）

## 環境の事実

- 2026-10-28 #1 `npm init` 既定の test スクリプトは必ず失敗するので、verify.sh では無いものとして扱う（検証: 2026-10-28）
- 2026-10-29 #2 ESPN はボットの User-Agent に 403 を返す。`season=Y` は Y 年開始のシーズンで終わった試合だけ、今後の試合は `fixture=true`（検証: 2026-10-29）
- 2026-10-29 #3 Google News の出典名は大文字小文字が媒体ごとに違う（MARCA・Diario AS・SPORT・EL PAÍS）。`site:` の実データで確かめてから書く（検証: 2026-10-29）
- 2026-10-29 #5 Google News は Cloudflare Workers からの取得に「automated queries」の 503 を返すことが多い。手元で取れても本番では取れないので、`wrangler dev --remote` で確かめる（検証: 2026-10-29）
- 2026-10-29 #6 ヘッドレス Chrome は幅500px未満の窓を作れない。390 を指定しても幅500で描画され、画像の右側が切れる（検証: 2026-10-29）
- 2026-10-29 #7 Cloudflare から取れる媒体の RSS: Guardian（Accept に XML が必要）・BBC・Marca・AS・MD・El País・Record・A Bola。Sport はボットに 406、O Jogo は RSS なし（検証: 2026-10-29）
- 2026-10-29 #8 CI（GitHub Actions）は `npm test` 内でビルドもする（test/build.test.mjs が CSP 違反になるインライン要素を検査）。`wrangler pages dev` は `_headers` を返すので CSP をローカルで確かめられる（検証: 2026-10-29）
- 2026-10-29 #12 `~/.gitconfig` に `fetch.prune = true` があると、明示した refspec の fetch が書いた ref を消す。スクリプトで fetch するときは `--no-prune` を付ける。worktree からは `FETCH_HEAD` が見えない（検証: 2026-10-29）
- 2026-10-29 #12 ヘッドレス Chrome は普段使いの Chrome と同じプロファイルだと固まることがある。`--user-data-dir` で使い捨てのプロファイルを渡す（検証: 2026-10-29）
- 2026-10-29 #15 YouTube の oEmbed（`/oembed?url=…`）は、実在する動画ならチャンネル名とタイトルを返し、埋め込み禁止なら 401 を返す。UEFA の動画は埋め込み禁止だった（検証: 2026-10-29）
- 2026-10-29 #18 クラウドのセッションは root で動くので、Chrome は `--no-sandbox` がないと起動しない。ヘルパープロセスが残ってプロファイルを消せないので、プロセスグループごと止める。サイトは `scroll-behavior: smooth` なので、クリック前のスクロールは `behavior: 'instant'` にする（検証: 2026-10-29）
- 2026-10-29 #19 `node --test` はテストファイルを並列で実行する。複数のファイルが dist/ をビルドすると ENOTEMPTY で落ちるので、ビルドは build.test.mjs だけで行う（検証: 2026-10-29）
- 2026-10-29 #20 `npm run dev` はポート 8788 が使用中だと起動に失敗するが、`npm run verify` や撮影はその別のサーバーを相手に走ってしまう。起動後にログの `Address already in use` と `lsof -iTCP:8788` を確かめる（検証: 2026-10-29）
