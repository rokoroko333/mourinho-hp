# トーン＆マナー（デザインの決まりごと）

コンセプト: **The Special One — 冷静な支配、内に燃える情熱。**
クールさは「夜の黒・鋭い角・詰めた大文字・余白」で、情熱は「赤を勝負の瞬間にだけ」使うことで表す。
金は格を示す細い線と数字にだけ使い、面を塗らない。値は `src/assets/styles.css` の `:root` が正本。

## 色

| 役割 | トークン | 値 | 使う場所 |
|---|---|---|---|
| 地 | `--bg` | #0B0D10 | 夜の黒（わずかに青み）。ページの背景 |
| 面 | `--surface` / `--surface-2` | #14171C / #1B1F26 | カード、表、入力 |
| 線 | `--border` | #262B33 | 区切り。強調したいときだけ `--hairline`（金の35%） |
| 文字 | `--text` / `--muted` | #F2EFEA / #9AA0A8 | 本文は温かい白。補足は灰（地との対比 7:1 以上） |
| 金 | `--gold`（`-light` `-dark`） | #C9A45C | 罫線、数字、ラベル、リンク。面の塗りは選択中の状態だけ |
| 赤 | `--red` | #E1251B | 勝負の瞬間だけ：カウントダウン、次の試合、再生ボタン、誤答。1画面の5%以下 |

- 金と赤以外の色相（緑・青など）を足さない。状態の違いは明るさと線で出す。
- 赤を装飾や見出しに使わない。使うと「瞬間」の効き目がなくなる。

## 文字

- 見出し・数字・ラベル・ボタン: `--display`（Barlow Condensed、600 と 800、`src/assets/fonts/` に同梱、OFL）。大文字、字間は見出しで詰め（-0.01em）、ラベルで広げる（0.12em）。
- 本文: `--sans`（端末の書体）。行間 1.6。
- 名言: `--serif` のイタリック。声の引用であることを書体で分ける。
- 数字は主役。成績・年・スコアは `--display` の 800 で大きく、`tabular-nums` で桁をそろえる。

## 形と動き

- 角: `--radius` 4px（カード・ボタン）。丸いピル型は使わない。
- 線: 区切りは 1px。セクション見出しの前に金の短い棒（24×3px）を置き、「1」の印にする。
- 影: 使わない（黒の上では濁る）。持ち上げはホバーで 2px 上げ、金の線にするだけ。
- 動き: 0.15〜0.2秒で決める。跳ねない。`prefers-reduced-motion` では止める。
- フォーカス: 金の 2px の枠（`:focus-visible`）。キーボードでも迷わないこと。

## 書き方（文言のトーン）

- 短く、断定的に。感嘆符と絵文字は使わない。
- 誇張しない。事実と数字で語る（出典のルールは CLAUDE.md）。
