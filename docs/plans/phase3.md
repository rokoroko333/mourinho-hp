## 1. 記録トラッカー（未着手）

- 「通算○○試合まであと何試合」など、近づいている節目。数字の起点は出典つきの値（`stats.json`）にする。
- 着手前にオーナーと決めること: 起点より後の試合を ESPN の結果から数えるか、出典の新しい値を待つか。
  どちらでも、`stats.json` の `current` と同じく、数え方と時点をページに書く。

## 2. 「誰に向けた発言か」クイズ（条件待ち）

- 名言から、誰（どの監督・選手・記者）に向けた発言かを当てる問題。
- 始める条件: `quotes.json` の出典つきの場面（`context`）で、相手がはっきり書かれた名言が十分にそろうこと。そろうまでは作らない。

## 完了条件（項目ごと）

- `npm run build` と `npm test` が通り、新しいページが4言語分（`en`・`es`・`pt`・`ja`）出力され、sitemap に載っていること（`noindex` のページは載せない）。
- 操作できる要素を足したら `test/flows/` にフローを足し、`npm run verify` の結果を PR に書くこと。
- 見た目が変わる PR は `npm run screenshot -- --pr <番号>` の画像を付けること。
