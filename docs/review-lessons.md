- 2026-11-01 #75 集計は、読むたびに全件を数えると読み取り量が票数×表示回数で増える。書き込み時にトリガーで件数を足しておき、読むのは件数の表だけにする。新しい表は既存のデータから埋め、古いコードが読む表（`tallies`）は残して、デプロイの順番がずれても数が狂わないようにする（検証: 2026-11-01）
- 2026-11-01 #74 「途中で止まる」「dry-run は何もしない」のような手順の約束は、実行する関数を差し込めるようにしてテストする。止まった後のステップが呼ばれないことを確かめる。名前の重複（タグ）のように後半で失敗しうる条件は、何かを本番に出す前に確かめる（検証: 2026-11-01）
- 2026-11-01 #73 「出てはいけない文字（undefined・null）」の検査は、`<script>` を飛ばすと構造化データの欠けを見逃す。HTML の本文は script を除いて調べ、JSON の script は解析して値を調べる。わざと null を入れて落ちることを確かめる。出典の日付は記事の公開日だけを書き、再公開日しか分からなければ省く（検証: 2026-11-01）
- 2026-11-01 #72 監視は「データの日付が新しいか」で見るが、KV が空や障害のときにその場で取得した応答も日付が新しい。cron 以外から来たデータには印（`live`）を付け、監視が止まった cron を見逃さないようにする。ESPN の複数の URL は、一部だけ成功したデータで正常なデータを上書きしない（検証: 2026-11-01）
- 2026-10-29 #2 外部 API の取得は、手で作ったデータのテストだけでは壊れていても緑になる。実データで1回呼んで結果を PR に書く（検証: 2026-10-29）

## 環境の事実

- 2026-10-29 #2 ESPN はボットの User-Agent に 403 を返す。`season=Y` は Y 年開始のシーズンで終わった試合だけ、今後の試合は `fixture=true`（検証: 2026-10-29）
- 2026-10-31 #57 #63 #64 #65 #67 ニュースの取得元は国（媒体）単位で選び、媒体の RSS で取る。Google News は本番の Cloudflare から断られる（503）ので、取得元を変えたら Google News を失敗させた本番と同じ条件で手元から取得し、媒体・国の内訳を PR に書く（`wrangler dev --remote` は本番の KV に書き込むので使わない）。トップ面の RSS にはモウリーニョの記事がほとんど載らないことがあり、タグの RSS（`/tag/jose_mourinho_a`）を探す。見出しは「Mou」とも書く。媒体名は Google News の `<source>` と完全に一致させる（1媒体の上限が両方に効くように）。偏りは国の枠と1媒体の上限を両方残して抑え、媒体を増やして埋める（検証: 2026-10-31）
- 2026-10-29 #8 CI（GitHub Actions）は `npm test` 内でビルドもする。`wrangler pages dev` は `_headers` を返すので CSP をローカルで確かめられる（検証: 2026-10-30）
- 2026-10-29 #12 `~/.gitconfig` に `fetch.prune = true` があると、明示した refspec の fetch が書いた ref を消す。スクリプトで fetch するときは `--no-prune` を付ける。worktree からは `FETCH_HEAD` が見えない（検証: 2026-10-29）
- 2026-10-29 #15 YouTube の oEmbed（`/oembed?url=…`）は、実在する動画ならチャンネル名とタイトルを返し、埋め込み禁止なら 401 を返す。チャンネル名で公式かどうかも確かめる（検証: 2026-10-29）
- 2026-10-29 #18 クラウドのセッションは root で動くので、Chrome は `--no-sandbox` がないと起動しない。サイトは `scroll-behavior: smooth` なので、クリック前のスクロールは `behavior: 'instant'` にする（検証: 2026-10-29）
- 2026-10-29 #19 `node --test` はテストファイルを並列で実行する。複数のファイルが dist/ をビルドすると ENOTEMPTY で落ちるので、ビルドは build.test.mjs だけで行う（検証: 2026-10-30）
